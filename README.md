# Jessica McIlree’s Web Portfolio

This project was created with **React.js** and **Tailwind CSS**, with background art by me (illustrated in Procreate).

## Features
- Learn more about me and my background
- View my projects and skills
- Contact me through the site

## Setup

To view the website locally, first download or clone the repository. Open your terminal and type:

git clone https://github.com/xjessxx/portfolio.git
cd portfolio

Make sure you have Node.js installed. If you don’t, open a terminal as administrator and run:
winget install OpenJS.NodeJS

Once Node.js is installed, install project dependencies:
npm install

Finally, start the development server:
npm start

This will launch the site in your default browser at http://localhost:3000.
